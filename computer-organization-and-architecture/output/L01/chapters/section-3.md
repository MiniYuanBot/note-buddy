# 03 主板与高速互连

[本讲目录](../index.md) · [课程目录](../../index.md) · [上一节：02 量化设计与实验](section-2.md) · [下一节：04 存储层次与内存墙](section-4.md)

## 主板的组成与兼容

主板为CPU、内存、扩展卡与外设提供连接、供电和运行配置。接口的物理形态决定怎样连接，控制器与拓扑决定数据经过什么路径。[^s1p33][^s2b10]

典型主板可按功能分为六个区域；具体位置与接口数量随型号变化。[^s2b10][^s2b11]

| 区域 | 主要组成与作用 |
| --- | --- |
| 后置I/O | USB、网络、音视频等外部接口；部分主板还有无线天线接口 |
| CPU与供电 | CPU插槽、供电接口和电压转换电路 |
| 内存 | DIMM插槽及连接内存控制器的线路 |
| 扩展 | PCIe插槽、M.2等扩展设备接口 |
| 芯片组 | 汇集多种外设接口，连接到CPU |
| 边缘接口与针脚 | 机箱前面板、USB、音频、风扇、水泵和灯光等连接 |

CPU插槽决定物理与电气连接能否匹配，ISA则规定机器指令接口。使用同一ISA的处理器，并不因此兼容同一插槽。传统PGA形式的CPU带针脚，插槽提供插孔；LGA形式把接触针脚放在插槽中。[^s1p34][^s2b12]

DDR内存代际不仅改变传输能力，也改变接口设计。DDR4与DDR5内存条的插槽不兼容，金手指和防呆缺口等特征需要与主板匹配；插槽安装顺序取决于主板布线，应按具体主板的规定选择。[^s1p35][^s2b10][^s2b12]

## 北桥、南桥与功能集成

传统主板把部分高速连接功能交给北桥，把外设I/O交给南桥。北桥协调主存等高速访问；南桥汇集多种外设I/O，再与系统其余部分通信。[^s1p35][^s1p36]

内存控制器等北桥功能集成到CPU后，CPU到内存的路径减少了中间环节，也缩短了高速信号路径。现代CPU还可以提供直连PCIe通道。[^s2b11][^s2b12]

芯片组继续承担接口扩展的职责。若每个低速外设都直接连CPU，会占用CPU有限的引脚和连接资源，并增加布线复杂度。让芯片组先连接这些设备，再经集中路径与CPU交换数据，可以扩展接口数量。[^s2b10][^s2b12]

## PCIe路径与带宽竞争

PCIe链路带宽随代际和实际通道数量变化。PCIe 4.0 ×4的单方向理论带宽近似为8 GB/s，PCIe 5.0 ×16近似为64 GB/s，相差约8倍。实际吞吐量还受设备能力、协议开销与整条路径限制。[^s2b10]

连接路径主要有两种：

- **CPU直连**：设备通过CPU提供的PCIe通道通信。
- **经芯片组连接**：设备先到芯片组，再通过芯片组与CPU之间的上行连接通信。多台设备可能共同使用这条路径。[^s2b12]

若多个设备同时传输，芯片组上行链路可能成为共同瓶颈。因此，设备接口的标称带宽并不保证在并发负载下仍能全部发挥。GPU带宽测试中，把GPU插到经南桥连接的PCIe插槽，就曾导致测得带宽达不到预期；诊断时需要检查插槽的实际连接拓扑与共享设备。[^s2b12]

**课堂强调**：做GPU等高速设备的性能实验时，先确认插槽是否直连CPU，以及途中有没有共享链路。[^s2b12]

PCI、PCI-X与PCIe是不同的扩展总线标准；传统PCI与PCIe插槽可以在同一主板上并存，需按接口类型和板上标识辨认。[^s1p33][^s1p36]

## 并行线路的时序约束

并行传输用多条线同时发送不同位，接收端需要在规定时刻正确接收整组数据。线路长度或传播条件不同，会使各位到达时间不同；频率越高，一个传输周期越短，容许的时序偏差就越小。[^s2b10][^s2b13]

主板上的内存线路因此常采用等长处理：有些线路弯曲，是为了调整长度，使同组信号更接近同时到达。内存插槽靠近CPU，也是在缩短信号路径。内存可达到的速率还取决于内存控制器、内存器件、主板和固件配置。[^s2b10]

PATA使用并行传输；SATA改用串行传输，减少多条并行数据线之间的同步负担，因而少针脚也可以支持较高传输速率。串行链路仍受信号完整性等条件限制，实际速度需要结合具体版本判断。[^s1p37][^s2b12][^s2b13]

近封装内存和靠近GPU的HBM也通过缩短连接距离改善高速互连条件。[^s2b13]

## 存储接口与协议

存储连接的名称可能指物理连接形式，也可能指接口与命令体系：[^s1p37][^s2b13]

| 名称 | 含义 |
| --- | --- |
| IDE／PATA | 传统ATA存储连接及其并行形式 |
| ATAPI | ATA体系中的分组命令接口 |
| SATA | 串行ATA存储接口 |
| SCSI | 存储设备使用的一套接口与命令体系，企业级存储中常见 |
| UFS | 手机等设备采用的闪存存储接口，使用SCSI命令体系 |
| M.2 | 主板上的一种设备连接形式；本例用于连接SSD |

传统主板可同时出现PATA与SATA；现代存储设备也可以通过PCIe路径通信。识别一块SSD的路径时，既要知道连接位置，也要知道该位置由CPU还是芯片组提供通道。[^s1p33][^s2b10]

## 供电、固件与辅助组件

CPU供电模块把电源输入的电压转换成CPU所需的低电压。示例以12 V输入、约1.3 V以内的CPU工作电压说明这一任务；实际工作电压随处理器与运行状态变化。MOS管、电感、电容和PWM控制共同参与供电，多相设计用于分担供电负载。[^s2b10]

主板固件保存硬件初始化和运行配置，BIOS设置界面允许调整部分参数。固件更新可以修复问题或增加硬件支持；配置不当导致无法启动时，主板可能提供设置重置功能，部分型号还有双固件芯片。[^s2b11]

其他组件各自承担明确职责：风扇和水泵接口供电并控制转速，前面板针脚连接开机键和指示灯，音频芯片处理音频，诊断灯或数码代码帮助定位启动问题。灯光接口也有电压与连接形式之别，例如12 V四针RGB和5 V三针可寻址灯光接口，不能仅按外观近似混接。[^s2b11]

芯片组规定可支持的扩展功能，厂商决定实际配备的接口。ATX、Micro-ATX、E-ATX、Mini-ITX等板型影响机箱适配和可布置空间，具体扩展能力还取决于型号配置。[^s2b11]

## 应用问答

**问**：GPU单独运行时正常，与多个芯片组设备同时传输时带宽下降，应先检查什么？

**答**：检查GPU插槽是否经芯片组，以及这些设备是否共享芯片组到CPU的上行链路。共享路径竞争可以解释并发时的下降。

**问**：为什么内存走线有时需要绕弯，而不是全部走最短直线？

**答**：并行信号需要满足到达时序。适当绕线可使不同线路接近等长；同时保持整体距离较短，有利于高速传输。
