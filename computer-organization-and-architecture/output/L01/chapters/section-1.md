# 01 抽象层与硬件接口

[本讲目录](../index.md) · [课程目录](../../index.md) · [下一节：02 量化设计与实验](section-2.md)

## 体系结构的分层作用

计算机体系结构把应用的信息处理需求，经逐层抽象与实现，连接到器件和制造工艺。算法决定计算步骤，硬件及其接口影响这些步骤如何执行和访问数据。[^s1p25][^s1p23][^s2b7]

系统栈从上到下各自回答不同的问题：[^s1p26][^s1p27][^s1p28][^s2b8]

| 层次 | 描述的对象 |
| --- | --- |
| 应用 | 要完成的任务，例如把一组数从小到大排列 |
| 算法 | 完成任务的步骤，例如反复选出最小值 |
| 编程语言 | 用C等语言表达算法 |
| 操作系统 | 管理硬件资源，协调程序运行 |
| 指令集架构（ISA） | 软件可使用的机器指令及其接口 |
| 微架构 | 用什么执行模块、数据通路和控制方式实现指令 |
| 寄存器传输级（RTL） | 寄存器之间如何传递数据、执行哪些逻辑操作 |
| 逻辑门级 | 布尔逻辑门及其组合 |
| 电路 | 把器件连接成能够工作的电路 |
| 器件 | 晶体管与连线等物理组成 |
| 工艺 | 制造硅器件所用的过程与技术 |

ISA规定指令的含义与接口；微架构组织硬件来实现这些指令；RTL描述寄存器与逻辑模块之间的数据传递。同一ISA可以由不同微架构实现。[^s1p28][^s2b8][^s2b9]

编译器把高级语言程序翻译成目标ISA的机器指令，操作系统负责资源管理与运行协调。指令集是编译器与处理器共同遵守的接口。[^s1p27][^s2b8]

## 从排序需求到C程序

非原地选择排序每次从尚未选出的元素中找到最小值，将它放到独立的输出数组中，再重复选择。对输入 `2,6,3,8,4,5`，依次选出 `2,3,4,5,6,8`。以下示例用数值 `100` 标记已经选过的元素：[^s1p26]

```c
void sort(int b[], int a[], int n) {
    for (int idx, k = 0; k < n; k++) {
        int min = 100;
        for (int i = 0; i < n; i++) {
            if (a[i] < min) {
                min = a[i];
                idx = i;
            }
        }
        b[k] = min;
        a[idx] = 100;
    }
}
```

这段代码适用于所有有效输入值都小于 `100` 的情况；`b` 必须有足够空间保存 `n` 个结果，且应与 `a` 分开存放。它会修改输入数组。[^s1p26]

1. 每轮令 `min = 100`，随后扫描整个 `a`。
2. 发现更小的值时，同时记录数值 `min` 与位置 `idx`。
3. 将本轮最小值写到 `b[k]`。
4. 将 `a[idx]` 改成 `100`，使它不再满足下一轮的 `a[i] < min`。

例如第一轮选出 `2`，输出 `b[0]=2`，输入变成 `100,6,3,8,4,5`；第二轮选出 `3`，写入 `b[1]`，再把该位置改成 `100`。重复值也能逐个选出，因为一次只标记一个位置。

若输入含有 `100` 或更大的值，某一轮可能找不到任何满足条件的元素。这时 `idx` 没有获得本轮有效位置：第一轮就失败时可能使用未初始化值，后续轮失败则可能重用旧位置。因此，`100` 的取值范围假设是算法正确性的必要条件。[^s1p26]

**补充解释**：该实现每轮都扫描 `n` 个元素，共进行 `n` 轮，比较次数随 $n^2$ 增长；独立输出数组需要 $n$ 个元素的空间。

## 指令接口的例子

MIPS32中的下列指令分别表达算术运算与数据传送。R型与I型是指令编码格式的名称：[^s1p27]

| 操作 | 示例指令 | 格式 |
| --- | --- | --- |
| 加法 | `addu` | R |
| 减法 | `subu` | R |
| 立即数加法 | `addiu` | I |
| 读入一个字 | `lw` | I |
| 写出一个字 | `sw` | I |
| 读入一个字节 | `lb` | I |

高级语言中的一次计算或数组访问，需要被翻译为目标机器支持的指令组合。机器执行这些指令时，硬件还必须安排数据读取、计算和结果保存；这些实现细节属于微架构与更低层次。[^s2b8]

## 逻辑、状态与互连

数字系统由三类基本组成共同完成任务：逻辑处理数据，状态保存数据，互连移动数据。[^s1p29]

| 基本组成 | 作用 | 通用计算机中的对应 |
| --- | --- | --- |
| 逻辑（Logic） | 对输入进行计算与判断 | 处理器 |
| 状态（State） | 保存当前与后续需要的数据 | 内存、存储设备 |
| 互连（Interconnect） | 在模块之间传送数据 | 总线、网络 |

在模块内部，逻辑计算结果由状态部件保存，再经互连送到下一步计算；在系统层面，这三类职责分别由处理器、存储器与网络承担。[^s1p30][^s2b9]

## 应用问答

**问**：运行同一组指令的两个处理器，内部数据通路必须相同吗？

**答**：不必。ISA规定指令接口，微架构决定具体实现；相同接口可以由不同硬件组织实现。

**问**：把排序示例的输入改成 `2,100,3`，为什么仅增加输出数组空间仍不能修好程序？

**答**：第三轮已没有小于 `100` 的元素，`idx` 无法获得有效的新位置。问题在哨兵与输入范围冲突，需要改变标记方法或限定输入，而非增加空间。
