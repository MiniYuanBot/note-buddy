# L01 体系结构基础

[课程目录](../index.md)

体系结构把程序需求落实到硬件设计。理解抽象接口、数据路径与资源约束，才能用实验判断性能、能耗和可靠性从哪里改善。

## 本讲小结

定位瓶颈需要沿实际路径分析：计算等待数据时检查缓存、主存和共享链路；依靠升频提升性能时核对电压与动态功耗；闪存出现读出错误时区分原始误码和纠错后的残余错误。比较方案前固定工作负载与约束，再用基线实验检验改动是否解决了目标问题。

## 不确定事项

- 视频主板实例中，s2b10称第一M.2接口直连CPU，而s2b12称该M.2连接南桥，具体归属尚未解决。正文保留两类拓扑及共享链路机制；使用该具体主板做带宽实验时，需按型号的连接拓扑确认该接口归属。
