# 08 原子更新与同步

[本讲目录](../index.md) · [课程目录](../../index.md) · [上一节：07 控制流与过程调用](section-7.md)

## 原子操作与锁

原子更新使共享位置的读改写产生不可分割的更新效果。若锁变量0表示空闲、1表示占用，两个核心用普通指令都先读到0、再各写1，就可能同时进入临界区。[^s1p66][^s2b14]

- **原子交换（swap）**：写入新值并返回旧值。将1与锁变量交换，旧值为0表示获得锁。
- **比较并交换（CAS）**：当前值等于期望值时才写入新值，比较与写入作为一次原子操作。

RISC-V的LR（load-reserved，保留加载）和SC（store-conditional，条件存储）通过保留机制构成原子更新循环；中间可以在本地寄存器中计算新值。[^s1p67]

## LR/SC的规则

LR加载数据，并为当前hart（硬件线程）建立保留集。SC尝试将新值写入目标地址，状态返回目的寄存器。以下例子采用自然对齐的64位位置：[^s1p68]

```asm
lr.d x5, (x6)        # 读8字节到x5并建立保留
# 在寄存器中计算新值
sc.d x7, x5, (x6)    # 尝试写入x5，状态写入x7
```

| SC结果 | 内存效果 | 返回状态 |
| --- | --- | --- |
| 成功 | 写入新值 | 0 |
| 失败 | 不写入 | 非零 |

判断SC能否成功，按以下顺序检查：[^s1p69]

1. 找同一hart最新的LR；每个hart同时只持有一个保留，新LR替换旧保留。
2. SC要写入的字节必须被当前有效保留集覆盖。覆盖是必要条件，SC仍可能额外失败。
3. LR与SC之间，另一hart对保留集的可观察写入会使SC失败；普通读取不是这类写冲突。
4. 任意一次SC，无论成败，都清除当前保留。

因此重试应回到LR重新读取、建立保留并计算，而非只重复SC。[RISC-V A扩展规范](https://docs.riscv.org/reference/isa/v20260120/unpriv/a-st-ext.html)

## 原子交换循环

下面交换x23与x20指向的64位内存值：[^s1p67][^s2b15]

```asm
again:
    lr.d x10, (x20)
    sc.d x11, x23, (x20)
    bne  x11, x0, again
    addi x23, x10, 0
```

1. LR把旧内存值读入x10并建立保留。
2. SC尝试写入x23原值；若失败，x11非零，回到LR重试。
3. 成功时x11为0，最后把x10中的旧值复制到x23，完成交换。

失败时未执行最后的addi，x23仍保存待写值。若初始内存为7、x23为12，一次成功后内存为12、x23为7；若其他核心先将内存改成9，使第一次SC失败，重新读取并成功后，交换出来的是9。[^s1p68][^s2b15]

原子加一可在LR与SC之间计算“加载值+1”，失败后重新读取和计算。用这些原语构造锁时，还须用正确的aq/rl或适当屏障保证受保护数据的访问顺序。[RISC-V A扩展规范](https://docs.riscv.org/reference/isa/v20260120/unpriv/a-st-ext.html)

## 三组边界例子

**例1：地址寄存器不同。** [^s1p69]

```asm
lr.w t0, (a0)
sc.w t1, a1, (a3)
```

比较实际地址和保留集：a3所指的写入字节未被覆盖时，t1非零；被有效保留覆盖时，SC可能成功。寄存器名不同不代表地址不同，保留集也可能大于LR读出的字节范围。

**例2：一个LR后有两个SC。** [^s1p69]

```asm
lr.w t0, (a0)
sc.w t1, a1, (a0)
addi a1, a1, 1
sc.w t2, a1, (a0)
```

第一次SC可能成功或失败，但都会清除保留。addi不建立保留，第二次SC必失败，t2非零。

**例3：两个LR后有两个SC。** [^s1p69]

```asm
lr.w t0, (a0)
lr.w t1, (a2)
sc.w t2, a1, (a0)
sc.w t3, a1, (a2)
```

第二个LR替换旧保留。第一次SC要根据a2建立的当前保留是否有效、是否覆盖a0写入字节判断。第一次SC执行后保留清除，第二次SC必失败，t3非零。[LR/SC保留规则](https://docs.riscv.org/reference/isa/v20260120/unpriv/a-st-ext.html)

## 应用问答

**问：计数器为10，两个核心都读到10。采用LR/SC加一，如何得到12？**

答：一个核心先成功写11，另一个SC因冲突失败；后者重新读11，计算12并提交。两次更新成功完成后为12。

**问：SC返回非零后，只重新计算新值并再执行SC可以吗？**

答：须先执行LR，因为失败的SC也清除了保留。[^s1p69]
