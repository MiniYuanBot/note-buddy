# 01 系统设计的约束

[本讲目录](../index.md) · [课程目录](../../index.md) · [下一节：02 性能指标与执行时间](section-2.md)

## 功耗墙与架构改进

提高频率可以缩短计算时间，但供电和散热限制了持续升频。频率提高若还需要提高电压，功耗增长会比频率增长更快。[^s2b1]

**补充解释**：CMOS动态功耗常用模型为$P_{dyn}=\alpha CV^2f$，其中$\alpha$是开关活动因子，$C$是等效电容，$V$是电压，$f$是频率。只有在$\alpha,C$近似不变且$V$随$f$近似成比例增加的简化条件下，才得到$P_{dyn}\propto f^3$；固定电压时，动态功耗对频率近似线性。

在相同频率下，架构仍可沿三条路径提高性能：

- 改善执行单元，使每单位时间完成更多有效计算。
- 加快数据供给，通过L1/L2/L3缓存和更高访问带宽，减少执行单元等待数据的时间。
- 改善指令调度，减少流水线空泡，让已有执行资源更充分地工作。[^s2b1]

## 多核与系统瓶颈

多核性能依赖计算任务能否分担，也依赖核心之间和核心之外的数据供给。主要约束如下。[^s2b1]

| 约束 | 机制与影响 |
| --- | --- |
| 核间互联 | 通信密集任务需要交换数据；互联带宽低会使计算资源等待传输 |
| 缓存副本一致性 | 一个核心修改共享数据后，其他核心的旧缓存副本需要失效或更新，产生额外通信 |
| 同步与调度 | 核心之间需要协调任务、等待依赖并保护共享数据，协调本身占用时间 |
| 缓存亲和性 | 任务再次使用某核心缓存中的数据时，留在该核心可减少搬移；迁移可能需要远程访问或重新加载 |
| 内存与存储供给 | 更多核心并发工作会提高DRAM容量、内存带宽和外存吞吐需求 |

通信密集的科学计算需要相应的核间带宽。早期AMD处理器的一次测量约为$6\,\mathrm{GB/s}$，仅对应所测设备。[^s2b1]

## 能效与散热

能效描述单位能量完成的工作量，能效提高意味着完成相同工作消耗的能量减少。系统节能既可以减少计算本身的消耗，也可以减少空闲、数据移动和散热的开销。[^s2b2]

| 方法 | 作用路径 |
| --- | --- |
| 工艺进步 | 改善器件和互联，可能降低所需电压、电容或延迟；实际收益取决于具体工艺与设计 |
| 异构计算 | 将不同任务交给适合的执行单元：CPU适合控制和顺序任务，GPU适合大量并行计算，FPGA、DSP、NPU等面向特定需求 |
| 存储层次改进 | 使用介于DRAM与SSD之间的新型介质，补充已有层次在容量、访问速度或能耗方面的不足 |
| 散热设计 | 利用合适的环境和冷却方式移走热量，并减少冷却系统自身耗电 |
| 虚拟化与资源复用 | 让高峰时段不同的用户共享设备，提高利用率，减少大量设备长期空转 |

理想几何缩放中，线性尺寸缩为$1/\sqrt2$，面积约减半；实际收益还取决于器件、互联和电路设计。[^s2b2]

单位计算工作能耗下降，可以使工作量快速增长而总能耗仅小幅增加。2010—2018年，全球数据中心的**计算实例数量增长550%，即增至原来的6.5倍**，同期总能耗增长约6%。[^s2b2] [历史能耗研究](https://datacenters.lbl.gov/sites/default/files/Masanet_et_al_Science_2020.full_.pdf)

## 可靠性与数据保持

可靠性要求设备持续提供正确结果，并在故障后尽快恢复服务。GPU的HBM可能发生位翻转，复杂芯片也可能存在触发特定指令流的硬件缺陷；光链路的连接质量和环境同样可能影响运行。存储可靠性尤其关系到已保存数据能否保持正确，而不仅是故障后能否重新启动。[^s2b3]

闪存利用存储的电荷状态区分数据。以下因素会使读出的状态偏离原先写入的状态：

- **老化与电荷俘获**：器件结构变化会影响充放电过程与读出结果。
- **单元间干扰**：对一个单元写入数据，可能扰动邻近单元。
- **随机噪声**：外部扰动等随机因素可能引起错误。
- **保持噪声（retention noise）**：即使没有读写，随时间变化，存储电荷也可能偏移。[^s2b3]

SSD长期离线保存也可能出现数据错误。一次实验中，约100块SSD离线三个月后，21块出现错误；该比例仅代表这次实验。[^s2b3]

## 原始错误率与ECC

纠错码（ECC）利用额外的校验信息识别并修复一定数量的错误。原始比特错误率（RBER）描述纠错前读出的错误；纠错后的错误率描述最终仍未被正确恢复的数据。[^s2b3]

以$4\,\mathrm{KiB}$数据页、$\mathrm{RBER}=3\times10^{-3}$为例：

$$
N_{bit}=4\times1024\times8=32768\ \mathrm{bit}
$$

$$
\mathbb E[N_{error}]=32768\times3\times10^{-3}=98.304
$$

即每页原始错误数的期望约为98。ECC再尝试恢复正确数据，讨论中的纠错后错误率目标为$10^{-15}$。[^s2b3]

BCH与LDPC体现纠错速度和能力的不同选择。在这里讨论的方案中，BCH计算较快、纠错能力较有限；LDPC计算较慢，但能纠正更多错误。LDPC还可分为硬判决与软判决：软判决引入额外信息和计算，能够容忍更高的原始错误率。两种判决方案所能承受的RBER差异形成可靠性余量。[^s2b4]

## 应用问答

**问：增加一倍核心后，通信密集程序加速很小，首先应检查什么？**

答：检查核间互联、共享缓存通信和内存带宽，以及同步等待；计算能力增加后，数据供给和协调可能仍是瓶颈。[^s2b1]

**问：一页$4\,\mathrm{KiB}$数据的RBER为$3\times10^{-3}$，最终读取必然有约98个错误吗？**

答：约98是纠错前错误数量的期望值。最终结果还取决于ECC是否能正确恢复该页。[^s2b3]
